# Azure Research

## 1. Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services for computing, storage, networking, databases, security, artificial intelligence, and application development. Azure is widely used by organizations that need cloud, hybrid, and enterprise solutions.

## 2. Global Infrastructure

Azure has a global infrastructure made up of datacenters, regions, and networking systems around the world. Azure has 70+ regions worldwide, allowing organizations to choose locations based on performance, compliance, and customer reach. Its regions are connected through Microsoft's global network to support reliable and low-latency cloud services.

## 3. Cloud Management Console

The Azure Portal is a web-based management console used to create, manage, and monitor Azure resources. Users can manage virtual machines, storage, networks, web applications, databases, billing, and other services from one unified interface. The portal also provides access to Cloud Shell and role-based access control.

## 4. Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provides virtual servers that allow users to run applications and workloads in the cloud. It is useful when organizations need control over their operating systems and computing environments.

### Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data such as documents, images, videos, backups, and application data.

### Azure Virtual Network

Azure Virtual Network allows Azure resources to communicate securely with each other, the internet, and on-premises networks. It provides networking features such as IP addresses, subnets, routing, and network security.

### Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service. It helps organizations manage users and control access to applications and resources.

## 5. Three Advantages

1. **Microsoft integration** – Azure works closely with Microsoft technologies and services, making it suitable for organizations already using Microsoft products.

2. **Global availability** – Azure provides a large worldwide infrastructure with many regions, allowing organizations to deploy applications closer to their users.

3. **Enterprise and hybrid support** – Azure provides services and management tools for cloud, hybrid, and on-premises environments. Its management services include monitoring, security, governance, protection, and migration.

## 6. Typical Enterprise Use Cases

Microsoft Azure can be used by enterprises for:

* Web and application hosting
* Virtual machines and infrastructure
* Data storage and backup
* Database applications
* Microsoft 365 and Microsoft technology integration
* Hybrid cloud environments
* Artificial Intelligence and Machine Learning
* Enterprise application development
* Data analytics and business intelligence
