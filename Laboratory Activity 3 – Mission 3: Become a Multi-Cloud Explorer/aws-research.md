# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many cloud services that organizations can use for computing, storage, databases, networking, security, analytics, and artificial intelligence. AWS was launched in 2006 and is used by startups, enterprises, government organizations, and other institutions.

## 2. Global Infrastructure

AWS has a large global infrastructure made up of Regions and Availability Zones. AWS currently operates 39 geographic Regions with 123 Availability Zones, with additional Regions and Availability Zones planned. This global infrastructure allows organizations to deploy applications closer to their users and improve availability and reliability.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Through the console, users can create and manage cloud resources, monitor services, manage users, check billing, and work with resources in different AWS Regions.

## 4. Four Core Services

### Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides resizable computing capacity in the AWS Cloud. It allows users to create and run virtual servers for different applications and workloads.

### Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve data such as files, images, backups, and application data. It is designed for secure and scalable storage.

### Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create a logically isolated network within AWS. It can be used to control networking, IP addresses, subnets, routing, and access to cloud resources.

### AWS IAM

AWS Identity and Access Management (IAM) helps organizations manage access to AWS resources. It allows administrators to control which users, roles, and applications can access specific resources and services.

## 5. Three Advantages

1. **Wide range of services** – AWS provides a broad selection of cloud and AI capabilities for different business and technical requirements.

2. **Global infrastructure** – AWS has a large worldwide infrastructure that supports applications and workloads across different geographic locations.

3. **Scalability and flexibility** – AWS allows organizations to scale resources according to their needs, helping them respond to changes in workload and business requirements.

## 6. Typical Enterprise Use Cases

AWS is used by enterprises for many different purposes, including:

* Website and application hosting
* Data storage and backup
* Database applications
* Data analytics
* Artificial Intelligence and Machine Learning
* Migration and modernization of existing IT infrastructure
* Business applications and enterprise systems
* Global applications that require scalable infrastructure
