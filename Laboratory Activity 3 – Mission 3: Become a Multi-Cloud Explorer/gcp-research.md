# GCP Research

## 1. Brief Overview

Google Cloud Platform (GCP), also called Google Cloud, is a cloud computing platform developed by Google. It provides services for computing, storage, networking, databases, data analytics, artificial intelligence, and application development. Google Cloud is commonly used for modern applications, data-intensive workloads, AI, and machine learning.

## 2. Global Infrastructure

Google Cloud has a global infrastructure made up of regions and zones. As of 2026, Google Cloud provides 43 regions and 130 zones across the world. Regions are geographic locations, while zones are deployment areas within regions. This infrastructure allows organizations to deploy applications closer to their users and improve availability and reliability.

## 3. Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. Users can create and manage virtual machines, storage, networks, databases, security settings, and other cloud resources through the console. It also provides access to different Google Cloud services and management tools.

## 4. Four Core Services

### Compute Engine

Compute Engine is a computing service that allows users to create and run virtual machines on Google's infrastructure. It can be used to host applications, websites, and other workloads.

### Cloud Storage

Cloud Storage is an object storage service used to store and retrieve data such as files, images, videos, backups, and application data. It can also provide multi-region storage options for applications that require high availability.

### Virtual Private Cloud (VPC)

Google Cloud VPC provides networking capabilities for cloud resources. It allows organizations to create networks, configure subnets, manage IP addresses, and control communication between resources.

### Cloud IAM

Cloud Identity and Access Management (IAM) allows organizations to control who can access Google Cloud resources and what actions they are allowed to perform. IAM uses roles and permissions to provide more granular access control and supports the principle of least privilege.

## 5. Three Advantages

1. **Strong AI and Machine Learning capabilities** – Google Cloud provides infrastructure and services designed to support AI and machine learning workloads, including specialized AI infrastructure.

2. **Global network and infrastructure** – Google Cloud operates a worldwide infrastructure with many regions, zones, and network locations that support global applications.

3. **Scalability and reliability** – Organizations can distribute workloads across different zones and regions to improve availability and protect applications from infrastructure failures.

## 6. Typical Enterprise Use Cases

Google Cloud can be used by enterprises for:

* Website and application hosting
* Data storage and backup
* Artificial Intelligence and Machine Learning
* Big data and analytics
* Kubernetes and containerized applications
* Database applications
* Software development
* Global web applications
* Data processing and business intelligence
