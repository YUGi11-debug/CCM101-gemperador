# Mission Reflection

## Mission 3 Reflection

Among the three cloud platforms, Google Cloud impressed me the most because of its strong focus on Artificial Intelligence, Machine Learning, data analytics, and Kubernetes. I learned that AWS, Azure, and Google Cloud provide many similar services, such as virtual machines, object storage, identity management, databases, and networking. However, each platform has different strengths and features that can make it more suitable for a particular organization or project.

Business requirements are important when selecting a cloud platform because there is no single provider that is best for every situation. A startup may prioritize scalability and cost, while a university using Windows Server and Microsoft 365 may benefit more from Azure. An AI research company may prefer Google Cloud because of its AI and machine learning capabilities, while a global e-commerce company may need a provider with strong global infrastructure and scalability.

Acting as a Cloud Solutions Consultant helped me understand that choosing a cloud provider is not simply about selecting the most popular platform. I need to first understand the client's requirements, budget, existing technologies, expected growth, and technical needs before making a recommendation. I also learned how equivalent services from different providers can be compared to find the most appropriate solution.

My GitHub Cloud Computing Portfolio also improved after completing this mission. I added organized research about AWS, Azure, and Google Cloud, comparison tables, client recommendations, and evidence from the activities. This makes the portfolio more useful because it shows not only what I learned about cloud computing but also how I can analyze different technologies and make decisions based on real business requirements. Overall, this mission helped me develop a better understanding of multi-cloud environments and the role of a Cloud Solutions Consultant.
